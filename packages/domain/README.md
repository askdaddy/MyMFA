# @askdaddy/domain

纯领域函数；接收已校验的 vault Entry / Tag，不读取平台状态，不解码密钥，不修改输入。变更返回新数组和变更记录，保留未知字段；未变记录可复用引用。调用方负责保存返回结果及更新 vault 元信息。

| API                                                                                                                 | 契约                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| sortEntries(entries, options)                                                                                       | 六模式：manual / issuer / account / usageCount / lastUsedAt / createdAt。使用次数、最近使用默认降序，其余默认升序；收藏优先，最近时间 null 最末，次级 issuer / account 升序，完全相同稳定。direction 可显式设 asc / desc；position 按原始字符序比较。 |
| keyBetween(before, after)                                                                                           | null 表示无边界；畸形键或反向区间抛固定 DomainError。                                                                                                                                                                                                 |
| rebalancePositions(items)                                                                                           | 保持当前 position 的原始字符顺序生成紧凑键，稳定处理同位记录。                                                                                                                                                                                        |
| appendEntry(entries, entry)                                                                                         | ID 由调用方提供，分配末尾位置；空表从 a0 开始。                                                                                                                                                                                                       |
| moveEntry(entries, id, beforeId, mode)                                                                              | 移至目标前，null 表示末尾，仅 manual 可拖动。正常仅改移动条目的位置；历史重复、无效、超过 20 字符的键先恢复，新键超过 20 字符则操作后重排。收藏显示是排序覆盖层，持久位置仍按 position 顺序计算。                                                     |
| addTag(tags, input) / updateTag(tags, id, patch) / moveTag(tags, id, beforeId)                                      | 标签 ID 由调用方提供；名称 trim 后忽略大小写唯一，名称和颜色不可为空。                                                                                                                                                                                |
| deleteTag(entries, tags, id, now)                                                                                   | 删除标签及关联，不删除条目；返回 entries / tags / affectedCount，每个受影响条目只计一次并更新 updatedAt。                                                                                                                                             |
| filterEntries(entries, tagIds, options?)                                                                            | 默认 any（OR），可设 all（AND）和 favoritesOnly；空选择保留全部符合收藏条件的条目，输出保留输入顺序。                                                                                                                                                 |
| searchEntries(entries, tags, query, options?)                                                                       | 异步返回 entry / score；搜索 issuer / account / note / 标签名，不搜索密钥。prefix > 词首 > subsequence，同类短字段优先，收藏优先于分数，其次 issuer / account，完全相同稳定。空查询只做稳定收藏分组。                                                 |
| recordUsage(entry, event, now) / setFavorite(entry, favorite, now)                                                  | copy / expand 计数，visible 不计；显式注入非负安全整数时间。计数溢出拒绝。                                                                                                                                                                            |
| normalizeHostname(value) / matchesSite(site, context, subdomains?) / matchingEntries(entries, context, subdomains?) | context 是 protocol / hostname，调用方解析 URL 并将国际域名转为 punycode。仅 http: / https:；默认包含子域，必须以点分隔。忽略合法数字端口、大小写及根点；IPv4 只精确匹配。IPv6、未转码 Unicode、userinfo、路径、畸形 DNS 返回 false。                 |

searchPinyin 默认 true，仅非空查询且候选字段包含汉字时动态加载字典，提供拼音首字母（如 zfb / wx / zgyh）。关闭、空查询和纯 ASCII 候选不加载。筛选后搜索由调用方组合两函数。

固定非加密依赖：fractional-indexing 4.0.0（CC0-1.0）及 pinyin-pro 3.29.4（MIT）。版本来自工作区 catalog；内部仅依赖 vault 类型。位置算法复用前者，拼音字典复用后者，不引入模糊搜索库。

在仓库根运行 pnpm --filter @askdaddy/domain test、pnpm --filter @askdaddy/domain typecheck、pnpm build。全仓 lint 在根运行 pnpm lint。QA 黑盒入口为 node test/domain-blackbox.mjs，先构建全部包。
